# How I log

Each entry follows the same five sections, every time — consistency makes old entries easy to scan and new ones fast to write:

| Section | What goes here |
|---|---|
| **Goal** | What I set out to learn or build this session/week |
| **What I did** | Concrete actions — code written, concepts studied, tools tried |
| **What confused me** | Honest friction points, not polished takeaways |
| **What I'd do differently** | The correction, in my own words (Socratic — I ask myself before I answer) |
| **Next** | What this unlocks or leads into |
